# Git Graph Implementation Plan

**Goal:** Add a read-only recent commit graph to the Git Repository panel.

**Architecture:** Extend the shared Git model with `GitCommit`, add a `git:log` IPC channel backed by `GitService.log()`, and have `GitPanel` load history on mount/refresh. Render a collapsible graph section above the commit box.

**Tech Stack:** Electron IPC, Node `git log`, React, Vitest, existing CSS.

## Tasks

### Task 1: Shared model and Git log parser
- Add `GitCommit` and `parseGitLog(output: string): GitCommit[]` to `src/shared/git.ts`.
- Test graph prefixes, refs, parent hashes, and empty output in `src/shared/git.test.ts`.

### Task 2: Main Git service and IPC
- Add `GitService.log(limit = 30)` using `git log --graph --decorate --date=iso-strict --pretty=format:%H%x1f%h%x1f%P%x1f%an%x1f%ad%x1f%D%x1f%s --max-count=<limit>`.
- Add `gitChannels.log`, preload `window.aureum.git.log`, and IPC handler.
- Test real repository history and unborn repo empty state in `src/main/git/gitService.test.ts`.

### Task 3: GitPanel graph UI
- Add state for commits, collapsed/open graph state, loading/error states, and refresh coupling.
- Render `GitCommitGraph` under the branch header and above commit textarea.
- Test graph rendering, empty history, collapse toggle, and existing stage/commit behavior.

### Task 4: Styling and verification
- Add CSS for graph header, rows, rail, refs, and empty state in `src/renderer/styles/app.css`.
- Run `npm test -- --run`, `npm run typecheck`, `VITE_MAX_WORKERS=1 npm run build`, and `git diff --check`.
- Commit and rebuild/install app package.
